SPORTIO LIVE

Connect to your account

Paste the UUID and password from your Sportio Live dashboard. Both are stored in this browser only. The password is needed to search your playlist and save channels.

One-time player setup

Clicking a stream hands its address to a media player on this device. Nothing is downloaded — the browser never fetches the stream itself, it only passes the address along. How the hand-off happens depends on the device, so pick yours.

        2. Tap any stream

        Which browsers this works in.
        Chrome, Edge, Brave, Opera and Samsung Internet all support the intent links this uses.
        Firefox for Android does not — there, use the
         button on any stream row to copy its address, then paste it into
        VLC under More › New stream. The copy button is on every row on a
        phone regardless, for anything else that will not open.
      

      

        One thing worth knowing.
        A stream address contains your IPTV username and password, the same as it does everywhere else in this app.
        The copy button puts it on the clipboard in full, so treat a pasted link the way you would the credentials
        themselves.
      

    

  


  
  

    

      On iPhone and iPad there is no script to install and nothing to register. A stream link addresses the player
      by the URL scheme that player claims when you install it, so the only thing that has to exist on the device is
      the player — and it has to be installed before the link will do anything.
    


    
    
      
  1. 
        1. Install a player
        — either of these. VLC is free outright and is the same player the
        Android side uses. Infuse is free to install with a paid unlock; it tends to be steadier on the awkward
        streams IPTV providers serve, and it shows the channel name while it loads instead of the address.

        is not.

        If a tap does nothing.
        On Android a link can name a web page to fall back to, so a missing player sends you to the store instead.
        iOS has no equivalent — a link to an app that is not installed
        just fails, and Safari may say nothing at all about it. So if nothing happens, the player named above is
        either missing or is not the one you picked. The  button on every
        stream row is the way round it: copy the address and paste it into the player by hand — in VLC under
        Network › Open Network Stream. That button is shown at every
        window size on iOS for exactly this reason.
      

      

        Which browsers this works in.
        Safari, Chrome, Edge and Firefox on iOS all follow these links. There is no equivalent here of the Android
        tab's warning about Firefox — opening an installed app by its URL scheme is something every iOS
        browser does.
      

      

        One thing worth knowing.
        A stream address contains your IPTV username and password, the same as it does everywhere else in this app.
        The copy button puts it on the clipboard in full, so treat a pasted link the way you would the credentials
        themselves.

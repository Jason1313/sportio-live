Connect to your account

Paste the UUID and password from your Sportio Live dashboard. Both are stored in this browser only. The password is needed to search your playlist and save channels.

One-time player setup

Clicking a stream hands its address to a media player on this device. Nothing is downloaded — the browser never fetches the stream itself, it only passes the address along. How the hand-off happens depends on the device, so pick yours.

        Which browsers this works in.
        Chrome, Edge, Brave, Opera and Samsung Internet all support the intent links this uses.
        Firefox for Android does not — there, use the
         button on any stream row to copy its address, then paste it into
        VLC under More › New stream. The copy button is on every row on a
        phone regardless, for anything else that will not open.
      

      

        One thing worth knowing.
        A stream address contains your IPTV username and password, the same as it does everywhere else in this app.
        The copy button puts it on the clipboard in full, so treat a pasted link the way you would the credentials
        themselves.
